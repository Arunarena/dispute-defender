> HOW TO CREATE A REAL SANDBOX DISPUTE
  1. Buy an item using your sandbox personal (buyer) account from developer.paypal.com → Testing Tools → Sandbox Accounts.
  2. The store records the order with a simulated tracking number, so the agent has evidence.
  3. Log in to sandbox.paypal.com as that buyer → Resolution Center → open a dispute on the payment (e.g. "item not received").
  4. Return to Dispute Defender, refresh, and deploy the agent on it.
